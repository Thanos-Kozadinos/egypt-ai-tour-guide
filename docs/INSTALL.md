# Installing Egypt Guide on a phone

## Android (Xiaomi 17 Pro, and any other Android)
1. Connect to Wi-Fi.
2. Open **Chrome** (not Mi Browser) and go to the app address (the GitHub Pages URL).
3. Wait for the first screen to load, then open Chrome's menu (three dots) and tap **Add to Home screen** or **Install app**. Confirm.
4. Open the new **Egypt** icon from the home screen (it runs full screen, without browser bars).
5. Tap **More -> Offline packs -> Download everything**. Leave the screen on until it says "ready offline". Typical size: 200-300 MB.
6. Test: turn on Airplane mode, open the app, search "Tut mask", play the audio.

Xiaomi notes
- If Chrome is missing (China ROM), install Chrome from the Play Store or sideload the APK first.
- Never run the "Cleaner" app on Chrome's data, and never tap "Clear site data": it would delete the packs.
- For background audio with the screen off, allow Chrome in Settings -> Battery -> no restrictions, if the phone stops playback.

## iPhone (for the second traveller)
1. Open the address in **Safari**.
2. Tap Share -> **Add to Home Screen**.
3. Open the icon, then More -> Offline packs -> Download everything.
4. Safari may limit storage; if the download fails, download one place at a time.

## Updating
When the app has a new version, open it once while online and it updates itself. Downloaded packs are kept.

## If a photo or audio does not play offline
Open More -> Offline packs and press Download on that place. Each press continues where it stopped.
